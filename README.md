# بوابة لجنة القياس والتقويم

تطبيق React + Vite لتحليل استبيانات الجودة، متابعة ملفات Google Drive، وإصدار تقارير Word وPDF.

## التشغيل

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

## بنية المشروع

- `src/`: واجهة التطبيق والمكوّنات ومحرك التحليل ومخططات الاستبيانات.
- `docs/`: التوثيق ودليل الاستبيانات ونظرة المشروع.
- `tools/`: أدوات التحليل المستقلة وإصدار التقارير خارج واجهة React.
- `legacy/`: أدوات HTML المرجعية القديمة المستخدمة للمقارنة أو التشغيل المستقل.
- `artifacts/`: مخرجات الفحص البصري وملفات QA.
- `public/`: الأصول الثابتة مثل الشعار.

بيانات الاستبيانات المحلية وملفات OAuth والبيئة المحلية مستثناة من Git عبر `.gitignore`.
